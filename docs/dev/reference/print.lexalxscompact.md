# Compact print method for list of entries

Compact print method for the output of
[`search_lexicon()`](https://stefanocoretta.github.io/lexa/dev/reference/search_lexicon.md),
which returns an object of class `lexalxscompact` when `show_entry` is
`FALSE`..

## Usage

``` r
# S3 method for class 'lexalxscompact'
print(x, ...)
```

## Arguments

- x:

  An object of class `lexalxscompact`.

- ...:

  Arguments passed to print.

## Value

Nothing. Used for its side effects.
