# Print method for list of entries

Print method for the output of
[`search_lexicon()`](https://stefanocoretta.github.io/lexa/dev/reference/search_lexicon.md),
which returns an object of class `lexalxs`.

## Usage

``` r
# S3 method for class 'lexalxs'
print(x, ...)
```

## Arguments

- x:

  An object of class `lexalxs`.

- ...:

  Arguments passed to print.

## Value

Nothing. Used for its side effects.
