# Import lexicon from LIFT file

It imports the lexicon from a LIFT file (exported from LexiquePro).

## Usage

``` r
import_lexicon_lift(lexadb, path)
```

## Arguments

- lexadb:

  A `lexadb` object as returned by
  [`load_lexadb()`](https://stefanocoretta.github.io/lexa/dev/reference/load_lexadb.md).

- path:

  The path to the lexicon LIFT file as a string.

## Value

Nothing. Used for its side effects.
