# Print method for Lexa databases

Print method for objects of class `lexadb`, which prints database info
and statistics.

## Usage

``` r
# S3 method for class 'lexadb'
print(x, ...)
```

## Arguments

- x:

  An object of class `lexadb`.

- ...:

  Arguments passed to print.

## Value

Nothing. Used for its side effects.
