# Lexa PDF document

A custom Rmarkdown template to typeset PDF documents with extra support
for interlinear glosses. Note that this format uses a custom Pandoc
LaTeX template, because of incompatibilities bewteen expex and
unicode-math.

## Usage

``` r
lexa_pdf(...)
```

## Arguments

- ...:

  Arguments passed to
  [pdf_document](https://pkgs.rstudio.com/rmarkdown/reference/pdf_document.html).
